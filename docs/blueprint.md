# **App Name**: AvatarSpeak

## Core Features:

- Message Input: Allow users to input text messages for the avatar to speak.
- Voice Input: Allow users to use their voice for their avatar to speak.
- Text-to-Speech Conversion: Convert the user's text or voice input into speech using selected voice settings.
- Avatar Animation: Animate the 3D avatar to visually represent speech and emotions (talking, thinking, neutral).
- Settings Customization: Enable users to adjust voice settings (rate, volume, voice selection) and avatar appearance via Ready Player Me integration, with persistent settings saved to a cookie.
- AI Message Generation: Leverage the Anthropic API to generate responses, and then output the responses to audio.
- Multi-User Persistent settings.: Update React avatar app to connect to the user login/registration backend that is provided. Have persistent user settings for their preferences. Have the ability for them to record their voice for audio transcription for messages, if desired.

## Style Guidelines:

- Primary color: Cyan (#00FFFF) to represent communication and modernity.
- Background color: Dark slate gray (#2F4F4F), creating a sophisticated and engaging backdrop.
- Accent color: Teal (#008080) to highlight interactive elements and important information.
- Body and headline font: 'Inter' sans-serif for clear, modern readability throughout the app.
- Use simple, outlined icons from Lucide-React to maintain a clean and modern interface.
- Use a split-screen layout with the 3D avatar on one side and the chat interface on the other to balance visual appeal with functionality.
- Implement subtle animations to enhance user experience, such as fading in new messages and avatar state transitions.
